# 隐藏路径与不存在路径使用相同的浏览响应

用户确认隐藏实际已经阻止访问，但密码页面暴露了目标可能存在；因此本次目标是让目录列表和文件详情中的隐藏路径表现得与不存在路径相同。统一相应“未找到”响应，密码校验失败继续保留密码提示，避免把真正需要密码的路径一起伪装成不存在。

范围为普通浏览 API 的 list、get，以及目录选择使用的 dirs。使用现有隐藏判定，对隐藏与缺失统一返回业务码 404、消息 `object not found`、空 data；保持现有 HTTP 200 JSON 封装。前端依据相同响应展示相同错误页面。

隐藏规则的匹配、继承、查看隐藏权限及签名/分享授权沿用现有行为。例如目录自身的 `.+` 描述该目录的子项，并不会隐藏该目录自身。
