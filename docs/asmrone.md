# ASMR.ONE 存储

在存储管理中选择 **ASMR.ONE**，挂载路径默认 `/ASMR_DLSite`，根目录必须为 `/`。先按每 10,000 个编号进入范围目录，再进入 `编号 标题`，例如 `/ASMR_DLSite/RJ110000~RJ119999/RJ117765 Title/原始文件树`。RJ、VJ、BJ 按编号数字部分共用范围目录，范围名统一以 RJ 开头，作品名保留原编号前缀。百万以下范围使用六位数字，百万及以上使用八位数字，例如 `RJ01010000~RJ01019999`。无法解析的编号归入“其他作品”。文件树保留上游结构，标题变化会改变访问路径。

默认 API 为 `https://api.asmr.one`。默认元数据请求速率为每秒 1 次，并发 1；同一上游的多个挂载共享限速，采用其中最保守的设置。每日增量同步作品目录，每周完整核对。首次建立目录时分批开放浏览，随后逐步补齐全部作品的文件树。

缓存默认位于 `<OpenList 数据目录>/cache/asmrone/<存储ID>/<API地址指纹>/cache.db`。自定义缓存根目录仍按存储和 API 地址隔离。SQLite 数据库与主数据库配置无关；备份时停止服务，或使用 SQLite 在线备份工具。不要只复制运行中的 `cache.db` 而忽略 WAL。

Modified 显示本地缓存最后变化的时间：作品资料新增、实际变化或恢复收录，以及文件树成功保存时推进。未变化的目录同步、普通刷新、内容读取和失败重试不推进。作品、其文件和生成的 README 使用该作品的时间，范围目录取其中作品的最近时间。变更时间独立持久保存，重启后保留。此前的缓存优先使用已有文件树保存时间，尚无记录的作品在下次目录同步或文件树补齐时开始记录。

**文件树成功获取一次后永久保存，包括空文件树。** 浏览、普通刷新、时间推进、重启和存储重新加载不会重新抓取。文件树请求失败会延后重试，旧缓存继续可用。完整目录核对成功后才隐藏下架作品，磁盘缓存保留；再次收录时复用。

`README.md` 由本地作品资料生成，在标题下展示封面，优先使用原图链接，缺少原图时使用缩略图链接。`cover.jpg` 和目录封面使用上游链接。已有同名真实文件优先。音频、图片和字幕内容不保存到本机。默认直连，可通过 OpenList 原有网页/WebDAV 下载策略切换代理。

存储编辑页提供同步面板：暂停/继续后台任务、立即增量同步、完整核对、重试失败任务和单作品刷新。单作品刷新接受上游 API ID 或作品编号；多版本共享编号时建议使用唯一 API ID。暂停状态和任务意图持久保存，暂停后台任务期间仍可按需浏览和手动刷新作品。

代理媒体读取遇到 HTTP 403、404、410 时尝试重抓该作品文件树并重试一次，保留 Range/HEAD；同一作品自动恢复设 5 分钟冷却。直连失败不会自动探测，需要手动刷新。刷新失败不替换旧缓存。

搜索直接读取同一份 SQLite 作品与文件树缓存，不构建或保存额外搜索索引；搜索引擎为 `none` 时也可使用。支持作品编号、标题及已缓存文件名的大小写不敏感包含匹配，多个关键词按 AND 匹配。曲目随缓存补齐立即可搜，改名、隐藏、恢复立即反映到结果。搜索和递归扫描均不会请求上游。路径范围、权限、分页、忽略路径和禁用索引设置继续生效；其他存储仍使用配置的索引引擎。旧的缓存索引任务表在打开缓存时移除。

管理员 API（沿用 OpenList 鉴权与响应格式）：

- `GET /api/admin/storage/asmrone/status?id=<存储ID>`
- `POST /api/admin/storage/asmrone/action`：`{"id":91,"action":"refresh","work_id":"RJ000007"}`
- 操作类型：`pause`、`resume`、`incremental`、`full`、`retry`、`refresh`。目录同步在暂停期间保持排队，继续后执行；单作品刷新独立运行。

关闭、禁用或删除存储不会删除磁盘缓存。更换 API 地址会建立独立缓存；不会自动切换镜像。
