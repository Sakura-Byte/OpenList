# JMComic 存储与阅读器

在存储管理中选择 **JMComic**，默认挂载 `/JMComic`，根目录为 `/`。使用匿名接口，不配置上游账号；首次元数据请求通过 `/setting` 初始化内存中的匿名 Cookie 会话，该请求也经过共享限速队列。默认 API 地址为 `https://www.cdnhjk.net`；公开移动端接口可能变化，可修改地址，不自动切换 API 镜像。

根目录包含今日推荐、推荐分组、日/周/月/总排行榜、分类、标签、最近更新和所有漫画。推荐等动态目录按上游排序默认保留前 200 部，可配置上限；标签自动包括上游 `/categories` 的主题标签和本地已缓存详情中出现的标签，管理员配置可补充标签。目录按本地已缓存作品数降序排列，计数对详情与入口成员去重，并随隐藏/恢复变化；这不是上游全库标签清单或全库总数。标签作品列表首次访问按需补齐，普通刷新只读已有缓存，后台刷新已访问的标签，不预抓所有标签作品。今日推荐是当前首页推荐快照，不保存历日推荐。

所有漫画按列表 **adddate** 归档为 `YYYY/MM/DD/JM编号 标题`；缺少可解析日期的作品暂存于“日期未知”。更新水位使用 **update_at**，增量同步重读水位对应的 UTC+8 日期。详情接口的 addtime 不作为上架日期。接口 total 可能截断，分页只根据有效结果与终止条件完成，重复页和无进展视为失败。

默认元数据请求每秒 1 次、并发 1，同一上游多个挂载共享最保守的限制。每日增量、每周核对，每 6 小时更新推荐。首次同步逐批开放目录；作品详情、章节及图片清单按需获取，同一 ID 合并并发请求，不进行图片预取。上游更新后按需刷新资料，失败保留旧缓存。完整核对缺失的作品只有经详情接口确认 404/410 才隐藏，确认阶段全部完成后事务提交隐藏操作；保留缓存用于恢复。

推荐、排行榜、分类和标签独立更新，单个入口失败会保留其旧快照，其余入口继续同步，面板记录带路径的错误。日榜等固定长度接口可能忽略页码，动态入口遇到无新增 ID 的页时停止并保存去重后的有效前缀；仍受入口数量上限约束。完整目录扫描遇到重复页仍视为未完成，不据此清理作品。所有入口成功后才清理过时的入口名称并推进推荐同步时间。

章节模板中的 config 和 result 支持 JSON 及上游 JavaScript 字面量形式（未加引号的属性名、单引号字符串、末尾逗号和注释）。仅解析字面量，不执行上游脚本、函数调用或表达式；模板异常时保留旧缓存。

部分目录条目的详情接口返回 `{"code":200,"data":[]}`。此时目录仍可浏览缓存的 README，网页显示暂时没有可用详情并提供重新获取按钮；已有详情缓存优先保留。空成功响应不作为确认下架的依据，也不保存成永久空详情。失败状态持久保存，普通浏览在五分钟内复用该结果；主动重试可提前获取，仍受限速和五分钟按钮冷却限制。

元数据使用独立 SQLite，默认缓存于 `<数据目录>/cache/jmcomic/<存储ID>/<API地址指纹>/cache.db`，可配置缓存根目录。缓存与主数据库类型无关。暂停、同步水位、待处理与失败任务持久保存。暂停时仍可按需浏览；重启或存储重新加载复用缓存，关闭、禁用或删除存储不删除缓存文件。备份时停止服务或使用 SQLite 在线备份，注意 WAL 文件。

## 网页入口

从普通目录选择作品后进入专属作品页，显示封面、简介、作者、可点击的标签、日期和章节；标签链接由服务端提供，并应用用户根目录和可见性检查。“开始阅读/继续阅读”或点击章节直接进入纵向阅读器。阅读器支持章节切换、页码定位和返回作品页，链接为章节目录路径加 `?view=reader`。进度按当前 OpenList 用户、上游、作品与章节 ID 保存在浏览器本地，不因从推荐或日期入口进入而分开。视口附近最多保留五张画布，释放远处图片和画布。服务端模式另有 `?view=files` 的图片文件视图。作品与章节页支持浏览器导出 EPUB、CBZ、PDF 和逐页图片 ZIP；不建立服务端图片或导出文件缓存。

作品资料位于左侧，封面位于右侧，窄屏自动换行。封面优先使用列表中的完整图片地址；缺少链接时使用上游 `/setting` 的 `img_host` 和标准 `/media/albums/<ID>_3x4.jpg` 地址，相对媒体地址也按该 CDN 解析。CDN 地址保存到元数据缓存并在重启后复用，普通列表和搜索不会为封面请求配置或图片内容。客户端由浏览器直接加载封面；服务端仍通过现有签名内容接口读取。封面失败不影响作品资料和章节入口。

## 读取模式

**client（默认）**：服务端只提供目录、README 与阅读元数据；作品和章节目录不列出逐页图片、封面文件或入口文件。浏览器直连上游图片并通过 Canvas 重排条带，封面直接加载。没有服务器图片流量，也不自动降级为代理。Canvas 不读取像素或导出，所以可以使用允许显示但不允许跨域像素读取的图片。直连失败可重试或刷新章节资料；刷新设五分钟冷却。浏览器与上游的网络和响应策略可能影响可用性。

WebDAV 可浏览目录与读取 README，图片 GET/HEAD 不受支持并返回 501 提示。需要普通下载、WebDAV 图片读取时，管理员切换到 server 模式。

**server**：服务端按需读取单页、解码并还原，静态页面输出 PNG，GIF 保持动画原格式。文件视图列出 `cover.jpg`、README、章节目录和按页序命名的图片。转换结果仅保留到最后一个正在使用的请求结束，不写磁盘、不跨请求保存，链接缓存不会继续持有关闭后的图片缓冲。

默认全进程同时存在一个转换结果，多个挂载使用最保守的并发设置，慢速传输也占用名额。默认单张输入上限 16 MiB、解码上限 1600 万像素、输出上限 32 MiB，均可配置。PNG 编码使用源图行映射，避免第二份完整像素副本。支持 GET/HEAD/Range；每次请求可能重新获取并转换整页，因此首次 HEAD 也可能消耗上游流量。目录列表与 PROPFIND 不为确定大小获取图片；尚未读取的图片大小暂为未知。

## 浏览器导出

两个读取模式均由浏览器逐页获取、打包并下载。`client` 直连上游并按原尺寸还原条带，需要上游允许 CORS 像素读取；失败时说明重试、刷新资料或由管理员切换 `server`，不自动代理。`server` 使用现有签名 OpenList 内容地址，图片已还原，浏览器不重复重排。导出只使用经用户权限过滤的章节与页清单，不保存服务端图片、文件或额外搜索索引。

作品页默认导出首章，章节页默认当前章节，也可选择整部作品。显示逐页进度并支持取消；页面离开会取消，缺页、请求失败和取消均不提供不完整文件。单次最多 3000 页，归档总量 256 MiB；PDF 图片总量 64 MiB。单张输入 16 MiB、输出 32 MiB、1600 万像素和宽高 16000 像素上限；这些浏览器限制独立于存储的服务端转换配置。每张解码图片与画布在请求结束后释放，归档 Blob 只在导出期间留在浏览器内存。

EPUB 使用漫画固定布局、章节导航及作品资料，按 [EPUB 3 容器与出版物规范](https://www.w3.org/TR/epub-33/)打包。CBZ 和 ZIP 按章节及页序保存还原 PNG。GIF 在 EPUB、CBZ、ZIP 中保留原始动画；PDF 使用第一帧静态图片。PDF 保持页序和原图比例，不包含评论或上游账号信息。

## 管理与接口

存储编辑页提供同步面板，显示作品、详情和章节缓存数、分页、任务、时间、缓存大小及错误。支持暂停/继续、立即增量、完整核对、推荐刷新、失败重试和单作品刷新。面板可见时每三秒轮询，离开停止。

- `GET /api/admin/storage/jmcomic/status?id=<存储ID>`
- `POST /api/admin/storage/jmcomic/action`：`{"id":91,"action":"refresh","work_id":"JM42"}`
- 操作：`pause`、`resume`、`incremental`、`full`、`feeds`、`retry`、`refresh`。管理员鉴权与现有响应格式一致；拒绝非 JMComic 存储。重复任务合并。
- `fs/list` 标签目录条目包含可选 `tag`（`name`、本地 `count`）字段。
- `fs/get`、`fs/list` 及作品/章节条目提供可选 `reader` 字段，明确说明 kind、mode、album_id、chapter_id。
- `POST /api/fs/other`：`{"path":"/JMComic/…/章节","password":"","method":"jm_reader","data":{"refresh":false}}`。返回作品资料、标签导航（`tag_links`）、章节导航、页清单、地址及还原参数；应用用户根目录、目录密码、隐藏和读取权限。服务端模式返回签名后的 OpenList 内容地址。

搜索直接读取现有 SQLite 缓存，无需构建或保存第二份索引；搜索引擎为 `none` 时也可使用。按编号、作品/章节/已缓存文件名做大小写不敏感包含匹配，多词 AND。结果只返回“所有漫画”的规范路径；从推荐、排行榜、分类、标签等入口搜索时按本地入口成员限定作品，别名不产生重复结果。客户端模式不返回图片文件，服务端模式可搜索已缓存页清单。标题、日期变化、隐藏和恢复直接反映到结果，无需自动更新索引。路径权限在分页前过滤，忽略路径及禁用索引设置仍生效。搜索与递归扫描零上游请求。旧的缓存索引任务表在打开缓存时移除。

## 验证约定

用模拟上游覆盖分页、假总数、重复页、增量/全量、同日更新、改名/改日期、下架恢复、部分失败、重启、限速、暂停、请求合并、缓存复用及搜索零请求。使用合成图片覆盖还原、余数行、格式、容量限制、取消、资源释放和 GET/HEAD/Range。浏览器使用模拟接口与合成图片验证阅读入口、直连流量、进度、历史、模式切换及管理面板，不以全库抓取测试。运行相关竞态检查、全仓 Go 测试、前端类型检查及生产构建；既有全仓问题单独记录。

协议与算法参考 JMComic-Crawler-Python（MIT），许可与版权说明见 `drivers/jmcomic/NOTICE`。

浏览器导出回归：Vite 启动后在独立空白页面执行 `(await import("/tests/jmcomic-export.browser.ts")).runExportTests()`，使用自产合成图片验证两种模式与四种格式、EPUB XML/容器、PDF 页数、条带余数行、GIF、取消、CORS、容量及资源释放。
